# Festive-Sales-Data-Analysis-using-Python
📌 Project Overview

This project focuses on analyzing festive sales data to understand customer purchasing behavior, sales trends, and product performance. The analysis was performed using Python and data visualization techniques to generate meaningful business insights.

🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

📊 Project Workflow

- Data Loading
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Customer Analysis
- Sales Analysis
- Product and Category Analysis
- Data Visualization
- Business Insights

🔍 Key Analysis

- Gender-wise sales analysis
- Age-group-wise sales analysis
- State-wise sales analysis
- Occupation-wise sales analysis
- Product category analysis
- Top-selling products
- Customer purchasing behavior

💡 Key Insights

The analysis helps identify customer segments, high-performing product categories, popular products, and important sales patterns that can support better business decisions.

🚀 Conclusion

This project demonstrates the use of Python for data cleaning, exploratory data analysis, visualization, and extracting meaningful insights from sales data.
